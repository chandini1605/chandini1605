## 🚀 Featured Projects

### 📉 Customer Churn Prediction Pipeline (Azure Databricks)
*Nov 2025 – Jan 2026*

Scalable end-to-end ML pipeline on about 7K telecom customer records (IBM Telco dataset), built with PySpark and Delta Lake. Features were selected using a correlation matrix, ANOVA F-Test and XGBoost feature importance. Logistic Regression, Random Forest and XGBoost were compared in MLflow, and the best XGBoost model was deployed as a real-time endpoint on Azure ML at **~88% accuracy**, with **40% less data-processing effort** through automation.

**Tech Stack:** Azure Databricks • PySpark • Delta Lake • MLflow • Azure ML • XGBoost • Scikit-learn

**Link:** [github.com/chandini1605/Customer_Churn_Prediction](https://github.com/chandini1605/Customer_Churn_Prediction)

---

### 📰 BBC News Clustering — NLP + Unsupervised ML (Azure Databricks)
*Jun 2026 – Aug 2026*

Unsupervised NLP pipeline that groups **2,225 BBC articles into 5 topics** without labels. It uses full text preprocessing, TF-IDF (5,000 features), TruncatedSVD and PCA, with K chosen by the Elbow Method and Silhouette Score. K-Means, DBSCAN and Agglomerative Clustering were compared, cluster stability reached **ARI 0.92**, and 3 configurations were tracked in MLflow.

**Tech Stack:** Azure Databricks • PySpark • Delta Lake • MLflow • NLTK • TF-IDF • K-Means

**Link:** [github.com/chandini1605/bbc-news-clustering-nlp-databricks](https://github.com/chandini1605/bbc-news-clustering-nlp-databricks)
